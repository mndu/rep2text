# Rep2Text — NeurIPS 2026 project page

Website: https://mndu.github.io/rep2text/

A static research page using the same layout as the SAEExplainer project page: centered paper metadata, bracketed links, the algorithm framework before Overview, and white panels for Overview, Results, and BibTeX.

Results retain two comparisons from the supplied paper: the Wikipedia baseline results of Table 2 and a text-reconstruction qualitative example from Table 3. All displayed values and author details were checked against `rep2text.pdf`. The previously removed cross-domain results section remains absent.

Open `index.html` locally to preview. No build process is required.
